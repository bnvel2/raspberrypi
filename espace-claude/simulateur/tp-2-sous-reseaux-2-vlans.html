TP Cisco : 2 sous-réseaux, 2 VLANs

Réseau 172.16.0.0/16 découpé en deux /17 (masque 255.255.128.0), routeur relié au switch par deux câbles

Deux câbles relient le routeur au switch : un par VLAN. Chaque interface du routeur porte l’adresse .2 de son sous-réseau, libre dans chaque plage, et sert de passerelle aux PCs (la même adresse sur le routeur et sur les PCs).

Question 4 du contrôle : les VLANs isolent les sous-réseaux au niveau 2, donc sans routeur les PCs ne se voient pas. La passerelle permet une communication contrôlée entre VLANs, car c’est le routeur qui assure le routage inter-VLAN.

Schéma synoptique

Configuration du routeur (2911)

Une interface par sous-réseau : pas de trunk ni de sous-interfaces.

Router>enable
Router#configure terminal
Router(config)#interface gigabitEthernet 0/0
Router(config-if)#ip address 172.16.0.2 255.255.128.0
Router(config-if)#no shutdown
Router(config-if)#exit
Router(config)#interface gigabitEthernet 0/1
Router(config-if)#ip address 172.16.128.2 255.255.128.0
Router(config-if)#no shutdown
Router(config-if)#end
Router#write memory

Vérification : Router#show ip interface brief (Gi0/0 et Gi0/1 en up/up) et Router#show ip route (les deux réseaux avec le code C).

Configuration du switch (2960)

Fa0/1 : câble vers Gi0/0 du routeur. Fa0/2 à Fa0/4 : PC0 à PC2. Fa0/5 : câble vers Gi0/1 du routeur. Fa0/6 à Fa0/8 : PC3 à PC5.

Switch>enable
Switch#configure terminal
Switch(config)#vlan 10
Switch(config-vlan)#name VLAN10
Switch(config-vlan)#exit
Switch(config)#vlan 20
Switch(config-vlan)#name VLAN20
Switch(config-vlan)#exit
Switch(config)#interface range fastEthernet 0/1 - 4
Switch(config-if-range)#switchport mode access
Switch(config-if-range)#switchport access vlan 10
Switch(config-if-range)#exit
Switch(config)#interface range fastEthernet 0/5 - 8
Switch(config-if-range)#switchport mode access
Switch(config-if-range)#switchport access vlan 20
Switch(config-if-range)#end
Switch#write memory

Vérification : Switch#show vlan brief (Fa0/1 à Fa0/4 dans VLAN10, Fa0/5 à Fa0/8 dans VLAN20).

Tests : PC0 vers PC1 doit répondre (même VLAN). PC0 vers PC3 doit échouer sans routeur, puis réussir une fois le routeur configuré (le premier paquet peut être perdu à cause de l’ARP, et le TTL de 127 montre que le paquet a traversé le routeur).

Si le ping ne passe pas : vérifier que la passerelle est renseignée sur chaque PC, que chaque câble est bien branché sur le port prévu (show vlan brief), et que les interfaces du routeur sont en up/up.

Les commandes expliquées

CommandeRôle
enablePasse en mode privilégié (prompt #).
configure terminalEntre en configuration globale.
interface gigabitEthernet 0/0Sélectionne l’interface du routeur reliée au VLAN 10 (Gi0/1 pour le VLAN 20).
ip address 172.16.0.2 255.255.128.0Donne l’adresse et le masque /17 : c’est la passerelle du sous-réseau.
no shutdownActive l’interface, désactivée par défaut sur un routeur Cisco.
vlan 10 / name VLAN10Crée le VLAN sur le switch et le nomme.
interface range fa0/1 - 4Configure plusieurs ports d’un coup.
switchport mode accessPort d’un seul VLAN, trames sans étiquette vers le PC ou le routeur.
switchport access vlan 10Affecte les ports au VLAN 10.
write memorySauvegarde la configuration pour le redémarrage.
show vlan briefListe les VLANs et leurs ports.
show ip interface briefAffiche l’état et l’IP des interfaces du routeur.
show ip routeLes deux réseaux apparaissent avec le code C (connecté).

Variante avec un seul câble : le port du switch passe en switchport mode trunk et le routeur utilise des sous-interfaces avec encapsulation dot1Q. Elle n’est pas utilisée ici, car le schéma comporte deux câbles.
