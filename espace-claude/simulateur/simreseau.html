📖 Documentation — SimRéseau

Tout ce que le simulateur sait faire, pour les TP réseau du bac pro CIEL.

SimRéseau fonctionne en deux temps. En ✏️ Conception on construit et on configure le réseau ; en ▶️ Simulation on le teste depuis la console des machines. Le travail est sauvegardé automatiquement dans le navigateur, et exportable en fichier.

1. Construire la topologie

  • Ajouter : en Conception, clique un équipement dans la palette de gauche, puis clique la zone pour le poser.
  • Déplacer : glisse un équipement. Les liaisons suivent.
  • Relier : clique le bouton 🔗 Relier, puis les deux équipements. Le premier port libre de chacun est utilisé automatiquement.
  • Configurer : clique un équipement → le panneau de droite affiche ses réglages.
  • Supprimer / débrancher : boutons en bas du panneau (ou touche Suppr sur l'équipement sélectionné).

2. Les équipements

ÉquipementNiveauRôle
💻 PC / 🖥️ ServeurHôteUne carte réseau (IP, masque, passerelle, DNS). Le serveur peut en plus héberger DHCP, DNS et un site web.
🔀 Switch2Commutateur : relie les postes d'un même réseau, gère les VLAN (ports Accès / Trunk).
🛰️ Routeur3Relie des réseaux différents : routage, sous-interfaces VLAN (802.1Q), routes statiques, pare-feu, DHCP.
⭐ Hub1Concentrateur : répète le signal sur tous les ports, sans gestion de VLAN. Utile pour illustrer la différence avec un switch.

3. Adressage IP

  • Sur un PC/serveur : Adresse IP, Masque, Passerelle et Serveur DNS.
  • Le masque s'écrit en décimal (255.255.255.0) ou en notation CIDR (/24).
  • Deux machines communiquent directement si elles sont dans le même sous-réseau ; sinon il faut une passerelle (un routeur).
  • Adressage automatique (DHCP) : voir section 7.

4. VLAN (niveau 2)

Sur un switch, chaque port relié se règle :

  • Accès + un numéro de VLAN : le poste branché appartient à ce VLAN.
  • Trunk : le port transporte tous les VLAN (étiquetage 802.1Q). À utiliser entre deux switchs, ou vers un routeur.

Deux postes ne se « voient » que s'ils sont dans le même VLAN. Pour faire communiquer deux VLAN, il faut un routeur (section 6).

5. Routage

  • Réseaux directement connectés : routés automatiquement entre les interfaces du routeur.
  • Routes statiques : réseau destination + masque + prochain saut (IP du routeur voisin). Nécessaire dès qu'un réseau n'est pas directement connecté.
  • Multi-routeurs : le moteur choisit la route au plus long préfixe et enchaîne de routeur en routeur ; une 0.0.0.0 /0 fait une route par défaut.

6. Routage inter-VLAN (router-on-a-stick)

Sur une interface de routeur, choisis le type Trunk 802.1Q puis ajoute une sous-interface par VLAN (numéro de VLAN + IP = passerelle du VLAN + masque). Côté switch, le port vers le routeur doit être en Trunk. Un seul lien physique route alors tous les VLAN.

7. DHCP

  • Service (sur un routeur ou un serveur) : crée une étendue — réseau/masque, passerelle distribuée, plage d'adresses, et serveur DNS optionnel.
  • Client (PC/serveur) : passe l'attribution sur Automatique (DHCP). Le bail obtenu s'affiche, et ipconfig le détaille.
  • Un client n'obtient une adresse que si un serveur DHCP est joignable dans son VLAN/réseau — sinon il reste sans IP.

8. DNS & serveur web

  • Serveur DNS (sur un serveur) : enregistrements nom → IP (ex. www.lycee.fr → 192.168.1.200).
  • Serveur web (sur un serveur) : activer le port 80, définir un titre et un contenu de page.
  • Côté hôte, renseigne un Serveur DNS (ou laisse le DHCP le distribuer) pour utiliser les noms.

9. Console & commandes

En Simulation, clique un PC/serveur pour ouvrir sa console. Les flèches ↑/↓ rappellent l'historique.

CommandeEffet
ipconfigAffiche IP, masque, passerelle, DNS et bail DHCP.
ping <ip>Teste la connectivité (ARP, routage, pare-feu).
ping <nom>Résout le nom par DNS puis teste la connectivité.
nslookup <nom>Interroge le DNS et affiche l'adresse.
http <nom|ip>Mini-navigateur : affiche la page du serveur web.
arpMontre les machines joignables dans le même VLAN.
aide · effacerListe des commandes · vide la console.

10. Pare-feu

Sur un routeur : une politique par défaut (autoriser, ou refuser = deny implicite façon ACL Cisco) et des règles ordonnées (action, protocole, source, destination, port). Elles sont évaluées de haut en bas à chaque routeur traversé, première correspondance appliquée. La console indique quand un paquet est bloqué.

11. Capture de trames

Bouton 📡 Trames : après chaque ping / requête, la capture liste les trames échangées (DHCP, ARP, ICMP, DNS, HTTP) avec source, destination, protocole, VLAN et détail — pour visualiser ce qui circule, à la manière de Wireshark.

12. Outils

  • ⛶ Plein écran : agrandit l'interface (Échap pour sortir).
  • ✕ en haut du panneau : le referme pour agrandir le schéma ; ⚙️ Panneau le rouvre.
  • 💾 Enregistrer / 📂 Ouvrir : sauvegarde la topologie en fichier .json et la recharge.
  • 🖼️ Image : exporte le schéma en PNG (idéal pour tes énoncés de TP).
  • 📋 Exemple, 🏷️ Exemple VLAN, 🧩 Exemple DHCP : topologies prêtes à tester.

13. Pour démarrer vite

Charge 🧩 Exemple DHCP, passe en Simulation, clique PC1 et tape successivement : ipconfig, ping www.lycee.fr, http www.lycee.fr. Ouvre 📡 Trames pour voir toute la chaîne DHCP → DNS → HTTP.
