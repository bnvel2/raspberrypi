Lab Packet Tracer : VLAN, trunk, router-on-a-stick, DHCP

Parcours en 7 étapes : suivez les onglets de gauche à droite.

1 · Schéma et plan d’adressage

Trunk 802.1Q (VLAN 10 et 20) VLAN 10 · COMPTA · 192.168.10.0/24 VLAN 20 · RH · 192.168.20.0/24

Adresses des PC attribuées par DHCP (relevées dans Packet Tracer) ; Gi0/0 du routeur n’a pas d’IP, elles sont portées par les sous-interfaces.

VLANNomRéseauPasserelle
10COMPTA192.168.10.0/24192.168.10.1
20RH192.168.20.0/24192.168.20.1

Câbles droits cuivre. Matériel : un routeur 1941 ou 2911, deux switchs 2960, quatre PC.

2 · Configuration de R1

Le prompt est indiqué avant chaque commande : saisissez uniquement ce qui suit le # ou le >.

Router>enable
Router#configure terminal
Router(config)#hostname R1
R1(config)#interface gigabitEthernet 0/0
R1(config-if)#no shutdown
R1(config-if)#exit
R1(config)#interface gigabitEthernet 0/0.10
R1(config-subif)#encapsulation dot1Q 10
R1(config-subif)#ip address 192.168.10.1 255.255.255.0
R1(config-subif)#exit
R1(config)#interface gigabitEthernet 0/0.20
R1(config-subif)#encapsulation dot1Q 20
R1(config-subif)#ip address 192.168.20.1 255.255.255.0
R1(config-subif)#exit
R1(config)#ip dhcp excluded-address 192.168.10.1 192.168.10.10
R1(config)#ip dhcp excluded-address 192.168.20.1 192.168.20.10
R1(config)#ip dhcp pool VLAN10
R1(dhcp-config)#network 192.168.10.0 255.255.255.0
R1(dhcp-config)#default-router 192.168.10.1
R1(dhcp-config)#dns-server 8.8.8.8
R1(dhcp-config)#exit
R1(config)#ip dhcp pool VLAN20
R1(dhcp-config)#network 192.168.20.0 255.255.255.0
R1(dhcp-config)#default-router 192.168.20.1
R1(dhcp-config)#dns-server 8.8.8.8
R1(dhcp-config)#exit
R1(config)#end
R1#write memory

3 · Configuration des switchs

SW1 (trunk vers R1 sur Fa0/1, trunk vers SW2 sur Gi0/1). Saisissez uniquement ce qui suit le prompt :

Switch>enable
Switch#configure terminal
Switch(config)#hostname SW1
SW1(config)#vlan 10
SW1(config-vlan)#name COMPTA
SW1(config-vlan)#exit
SW1(config)#vlan 20
SW1(config-vlan)#name RH
SW1(config-vlan)#exit
SW1(config)#interface fastEthernet 0/1
SW1(config-if)#switchport mode trunk
SW1(config-if)#exit

SW1(config-if)#switchport mode trunk
SW1(config-if)#exit
SW1(config)#interface fastEthernet 0/2
SW1(config-if)#switchport mode access

SW1(config-if)#exit

SW1(config-if)#switchport mode access
SW1(config-if)#switchport access vlan 20
SW1(config-if)#exit
SW1(config)#end

4 · Les commandes expliquées

CommandeRôle
no shutdownActive l’interface, désactivée par défaut sur un routeur.
interface gi0/0.10Crée une sous-interface logique ; aucune IP sur l’interface physique.
encapsulation dot1Q 10Associe la sous-interface aux trames étiquetées VLAN 10 (le vrai VLAN ID).
ip address 192.168.10.1 …Passerelle par défaut des machines du VLAN 10.
ip dhcp excluded-addressRetire des adresses de la plage distribuée (passerelle, équipements fixes).
ip dhcp pool VLAN10Crée le pool DHCP du réseau 192.168.10.0/24.
default-router, dns-serverPasserelle et DNS transmis aux clients.
vlan 10 / name COMPTACrée et nomme le VLAN sur le switch.
switchport mode access + access vlan 10Port d’un PC placé dans le VLAN 10.
switchport mode trunkPort qui transporte plusieurs VLAN en 802.1Q.
write memorySauvegarde la configuration (running → startup).

5 · Vérifications et dépannage

SW1#show vlan brief
SW1#show interfaces trunk
R1#show ip interface brief
R1#show ip dhcp binding
R1#show ip route

Chaque PC : Desktop → IP Configuration → DHCP. Attendu : 192.168.10.11 et plus en VLAN 10, 192.168.20.11 et plus en VLAN 20.

Test : ping de PC1 vers sa passerelle, puis vers PC4. Le premier paquet peut être perdu (ARP), c’est normal.

Pas d’adresse DHCP ? Vérifiez que Gi0/0 n’est pas en shutdown, que les deux trunks sont actifs et que les ports PC sont dans le bon VLAN.
