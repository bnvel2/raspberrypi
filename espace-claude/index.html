SimRéseau

Réécriture du « Simulateur réseau » v2 de Pierre Loisel (Réseau CERTA), sans le bug de Windows 11 qui posait plusieurs PC ou switchs à la fois. Quatre modes : Conception, Ethernet (hub, switch, collisions CSMA/CD, VLAN, spanning tree), IP (ARP, routage, ping, Internet) et Transport (ports TCP/UDP, NAT/PAT, filtrage).

  1. Cliquer sur la carte ci-dessus pour télécharger SimReseau-final.exe.
  2. Double-cliquer sur le fichier : aucune installation, aucun framework .NET nécessaire.
  3. Si Windows affiche « Windows a protégé votre ordinateur » : « Informations complémentaires » puis « Exécuter quand même » (le programme n’est pas signé).
  4. Menu Fichier › Exemples pour démarrer, ou Fichier › Ouvrir pour reprendre un réseau .xml de l’ancien simulateur CERTA.

Sur GitHub, le fichier se télécharge aussi depuis le dossier espace-claude/logiciel/ (bouton « Download raw file »).

Piloter Home Assistant avec Claude : mise en route

Objectif : permettre à Claude Desktop de lire l’état de la maison et de commander les appareils que vous choisissez, grâce à l’intégration officielle « Model Context Protocol Server » de Home Assistant.

1. Prérequis

  • Home Assistant à jour (HA OS, Container ou autre), accessible depuis l’ordinateur.
  • Claude Desktop et Node.js installés sur l’ordinateur (pour npx).
  • L’assistant « Assist » actif : c’est lui qui décide ce que Claude peut voir.

2. Activer l’intégration

  1. Paramètres → Appareils et services → Ajouter une intégration → Model Context Protocol Server.
  2. Choisir l’assistant (Assist) qui sera exposé.
  3. Valider : le serveur répond ensuite sur /api/mcp (anciennes versions : /mcp_server/sse).

3. Choisir les appareils exposés

Paramètres → Assistants vocaux → onglet « Exposer » : n’exposez que le nécessaire (lumières, prises, capteurs). Ce que vous n’exposez pas reste invisible pour Claude.

4. Créer un jeton d’accès

Profil (en bas à gauche) → Sécurité → « Jetons d’accès de longue durée » → Créer. Copiez-le tout de suite : il ne sera plus affiché.

Secret : le jeton donne accès à votre maison. Ne le publiez jamais (ni dans GitHub, ni dans une capture d’écran).

5. Brancher Claude Desktop

Réglages → Développeur → Modifier la configuration, puis ajouter (remplacer l’adresse et le jeton par les vôtres) :

{
  "mcpServers": {
    "home-assistant": {
      "command": "npx",
      "args": [
        "-y", "mcp-remote",
        "http://ADRESSE_DE_HOME_ASSISTANT:8123/api/mcp",
        "--header", "Authorization: Bearer VOTRE_JETON"
      ]
    }
  }
}

Redémarrez Claude Desktop. Les outils Home Assistant apparaissent dans la conversation.

6. Premiers essais

  • « Quelles lumières sont allumées ? »
  • « Éteins la lumière du salon. »
  • « Quelle est la température dans la chambre depuis ce matin ? »

7. Bonnes pratiques

  • Commencez par des appareils sans risque (lumières, prises) ; évitez d’exposer serrures, alarme ou portail.
  • Gardez Home Assistant sur le réseau local ; pour un accès distant, utilisez un VPN plutôt qu’une ouverture de port.
  • En cas de doute sur le jeton : supprimez-le dans le profil et créez-en un autre.
