# Espace Claude

Travaux réalisés avec Claude (bac pro CIEL).

- `index.html` : page d’accueil à trois onglets (Simulateur, Logiciel, Home Assistant)
- `simulateur/` : TP Cisco Packet Tracer, outils et simulateur réseau
- `logiciel/` : programmes Windows à télécharger (SimReseau-final.exe, simulateur réseau sans installation)
- `home-assistant/` : documentation Home Assistant

Pour consulter en ligne : activer GitHub Pages sur la branche `main`, puis ouvrir `/espace-claude/`.
