# Espace Claude

Travaux réalisés avec Claude (bac pro CIEL).

- `index.html` : page d’accueil à trois onglets (Simulateur, Logiciel, Home Assistant)
- `simulateur/` : TP Cisco Packet Tracer, outils et simulateur réseau
- `logiciel/` : programmes Windows à télécharger (SimreseauServeurV2.exe avec services DHCP/DNS/Web, SimreseauV4.exe version précédente, simulateur réseau sans installation, Bastion pare-feu pour Windows et Linux dans `bastion-windows.zip` / `bastion-linux.zip`, code dans `logiciel/bastion-pare-feu/`, et les installeurs tiers WordCraft, GridCraft et DeckCraft du projet ArtCraft, équivalents libres de Word, Excel et PowerPoint)
- `home-assistant/` : documentation Home Assistant

Pour consulter en ligne : activer GitHub Pages sur la branche `main`, puis ouvrir `/espace-claude/`.
